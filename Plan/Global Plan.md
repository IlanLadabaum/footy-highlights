# Global Plan — Footy Highlights

*Top-level plan. Detailed topics live in the sub-plans linked below. Status markers follow `Coding_Agent_Skill.md`: only [DECIDED] items may be built.*

## Vision

A free, open-source app that collects official football match highlight videos and presents them **without giving away results**. The user should be able to see which matches have highlights available, pick one, and watch it, without learning the score or the result anywhere along the way.

- [DECIDED] **Project name: Footy Highlights.** *(user, 2026-10-11)*

- [DECIDED] **Rewrite from the ground up.** The old implementation (archived in `legacy/`) is reference material for ideas only. *(user, 2026-10-11)*
- [BUILT] Old code archived in `legacy/`. The old virtualenv and app builds are in `legacy/env_and_builds/` (git-ignored, ~530 MB, deletable).
- [DECIDED] **Spoiler protection is the core principle.** Minor residual risk is acceptable when the only alternative is breaking YouTube's terms. Details: [Spoiler Protection](Spoiler%20Protection.md).
- [DECIDED] **Show every highlight video**, under a **neutral title generated by the app** (teams + competition + round where relevant). *(user, 2026-10-11)*
- [DECIDED] **Open source on GitHub; must comply with YouTube's Terms of Service and API policies.** *(user, 2026-10-11)* This rules out CSS injection, overlays on the player and downloading; see [In-App Player](In-App%20Player.md).
- [DECIDED] **Platform: macOS first.** iPad only if and when it's needed; keep the code iPad-friendly but don't build for it. *(user, 2026-10-11)*
- [DECIDED] **Tech stack: Swift + SwiftUI multiplatform app** (macOS now, iPadOS later), with WKWebView + YouTube IFrame API for playback. *(Choice delegated to the agent by the user, 2026-10-11; rationale in [In-App Player](In-App%20Player.md#tech-stack).)*
- [DECIDED] **In-app playback** with as little YouTube UI as the terms allow. Spike done; design in [In-App Player](In-App%20Player.md).
- [DECIDED] **YouTube is the video platform.** There is no free, legal, API-backed alternative. Video access sits behind a provider interface so others could be added. See [Video Sources](Video%20Sources.md#principles).
- [DECIDED] **Competition-agnostic pipeline.** Competitions are configuration. v1 covers the core competitions only; the bonus list is held for later. *(user, 2026-10-11)*
- [DECIDED] **Competition priority:** Premier League and Champions League first, then Serie A, Carabao Cup, Ligue 1, Bundesliga and La Liga where sources allow. *(user, 2026-10-11)*
- [DECIDED] **Prefer extended highlights** over normal when both exist. *(user, 2026-10-11)*
- [DECIDED] **La Liga is included, via ESPN FC.** Matches it skips show "No highlights available", with a fallback to open on YouTube in the browser where a video exists. *(user, 2026-10-11)*
- [DECIDED] **Watched status is not synced** across devices for now. *(user, 2026-10-11)*
- [DECIDED] **Fixture data: football-data.org, optional per-user key** (developer's key is configured and verified). *(user, 2026-10-11)*
- [DECIDED] **Pre-round league table is in the first build** (moved from future features). *(user, 2026-10-11)* Details: [League Table Context](League%20Table%20Context.md).
- [DECIDED] **UI: per-league drill-down**: competitions → rounds → round (fixtures + table) → player screen. Details: [App Structure & Data Flow](App%20Structure%20%26%20Data%20Flow.md).
- [DECIDED] [BUILT] **Secrets live in a git-ignored `.env`**, with a committed `.env.example`. Each user brings their own YouTube API key (and fixture-data key); setup steps are in the README. *(user, 2026-10-11)*
- [DECIDED] [BUILT] **Git repo for this project folder only** (`git init -b main`, 2026-10-11; no commits yet). **MIT licence** (`LICENSE`). *(user, 2026-10-11)*
- [DECIDED] **The developer will run updates and installs when asked** (macOS update, Xcode, registering API keys). *(user, 2026-10-11)*
- [DECIDED] **US-only availability is a known issue, deferred.** *(user, 2026-10-11)* [PROPOSED] Solve it later with region-specific source configs (see [Video Sources](Video%20Sources.md)).
